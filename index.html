How booking works

Four simple steps from search to boarding.

  1. Search

    Choose your departure port, destination, date and passenger count.

  2. Compare

    Review journey times, vessel details, fares and availability.

  3. Reserve

    Enter passenger details and review the total before confirming.

  4. Travel

    Keep your booking confirmation ready to show at the port.

Before you travel

Boarding

Arrive at the terminal early and keep valid identification ready.

Luggage

Check the vessel operator's luggage allowance before departure.

Travel requirements

Some island routes may require permits and additional documents.

Service updates

Check official operator announcements for delays and cancellations.

Need the full booking system?

This GitHub Pages version is a frontend showcase only. The original Django project in the repository contains the backend features, but GitHub Pages cannot run Python or connect to its server-side database.
